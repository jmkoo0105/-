# 단어장 (Rise Above Challenges)

서버 없이 돌아가는 단어 암기 사이트예요. GitHub Pages에 올리면 바로 쓸 수 있어요.

## 기능
- **사전**: 검색, 범위·형광펜 필터, 발음 듣기, 체크해서 시험 볼 단어 고르기
- **플래시카드**: 탭해서 뒤집기, 좌우로 넘기기, 순서 섞기, 앞면(단어/뜻) 바꾸기
- **단어 → 뜻** / **뜻 → 단어**: 4지선다 퀴즈 (10·20·30·50문제·전체)
- **학습 범위**
  - 지정 범위: 범위를 골라서 학습 (여러 개 선택 가능) + 형광펜 단어만 보기
  - 직접 선택: 사전에서 체크한 단어만 골라서 시험
- **틀린 문제 다시 풀기**: 시험이 끝나면 그 시험에서 틀린 문제만 다시 풀 수 있고, 다 맞힐 때까지 반복할 수 있어요 (홈 화면에도 표시돼요)
- 고른 단어와 마지막 시험에서 틀린 문제는 브라우저에 저장돼요

## GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만들어요 (예: `vocab`).
2. `index.html`, `style.css`, `app.js`, `words.js` 파일을 업로드해요.
3. 저장소의 **Settings → Pages**로 가요.
4. **Source**는 `Deploy from a branch`, **Branch**는 `main` / `/ (root)`로 고르고 저장해요.
5. 1~2분 뒤에 `https://아이디.github.io/vocab/` 주소로 열려요.

## 단어 추가하기
`words.js` 맨 아래에 범위를 하나 더 붙이면 돼요.

```js
addRange('Lesson 4', 'p.2', '어휘', `
resilience | n. 회복탄력성, 회복력
*be free from | id. ~이 없다, ~에서 자유롭다
`);
```

- 사진 한 장 = 범위 하나예요. 괄호 안은 차례대로 묶음 이름, 범위 이름(페이지), 부제예요.
- 같은 묶음 이름을 쓴 범위끼리 홈 화면에서 한 묶음으로 보여요.
- `단어 | 뜻` 형식이고, 한 줄에 한 단어예요.
- 앞에 `*`을 붙이면 형광펜(중요) 단어가 돼요.
- 뜻 앞의 `n.` `v.` `a.` `adv.` `id.`는 품사 표시로 자동 인식돼요.
- 같은 범위 안에 같은 단어가 또 나오면 뜻을 합쳐서 하나로 만들어요.
